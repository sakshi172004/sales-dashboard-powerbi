# 📊 Sales Dashboard (Power BI)

## Overview
This project is an interactive sales dashboard built using Power BI to analyze business performance across different dimensions.

## Key Metrics
- Total Sales: 2.30M
- Total Orders: 10K
- Total Quantity: 38K
- Total Profit: 286K
- Profit Margin: 12%

## Key Insights
- Sales increased significantly after 2015
- Technology category generated the highest revenue
- Consumer segment contributed the most sales
- Standard shipping mode is most frequently used
- Profit margin remained stable (~12%)

## Tools Used
- Power BI
- Data Visualization
- Data Cleaning

## Features
- Interactive filters (region)
- Sales trends over time
- Category-wise performance analysis
- Segment distribution

## How to Use
1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Explore the dashboard with filters
